# MACアドレス固定IP割り当て一覧
#
# このファイルの内容を RTX830 に貼り付けて実行すると固定IP割り当てが追加されます。
# デバイスを追加したら dhcp scope bind の行を追記して save で保存してください。
#
# 【IPアドレスの使い分け】
#   192.168.11.  2 〜  49 : 固定割り当てゾーン（このファイルで管理）
#   192.168.11. 50 〜 191 : DHCP 動的配布（新規デバイス自動取得）
#   192.168.11.192 〜 254 : 予備
#
# 【MACアドレスの確認方法】
#   Windows : コマンドプロンプトで  ipconfig /all  → 「物理アドレス」
#   macOS   : ターミナルで          ifconfig en0   → 「ether」
#   Linux   : ターミナルで          ip link        → 「link/ether」
#   Android : 設定 → Wi-Fi → 対象ネットワーク → 詳細 → MACアドレス
#   iOS     : 設定 → Wi-Fi → (i) → MACアドレス（プライベートMACがOFFの場合）
# -----------------------------------------------------------------------

# -----------------------------------------------------------------------
# 固定IP割り当て設定
# -----------------------------------------------------------------------

dhcp scope bind 1 192.168.11.18 ethernet b8:27:eb:ba:0b:00  # DNS MAIN
dhcp scope bind 1 192.168.11.28 ethernet 88:a2:9e:88:00:14  # HEMS PI4
dhcp scope bind 1 192.168.11.40 ethernet c4:3c:ea:2b:63:90  # WSR-3200AX4S

# 追加する場合はここに続けて記載:
# dhcp scope bind 1 192.168.11.xx ethernet xx:xx:xx:xx:xx:xx  # デバイス名

# -----------------------------------------------------------------------
# 設定確認コマンド（適用後に実行して確認）
# -----------------------------------------------------------------------
# show dhcp scope
# show dhcp binding

# -----------------------------------------------------------------------
# 適用後に保存
# -----------------------------------------------------------------------
