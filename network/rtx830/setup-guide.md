# YAMAHA RTX830 初期設定手順
NTT フレッツ光 + アンドライン (IPoE / v6プラス MAP-E)

## 接続方式の概要

| 通信 | 方式 |
|------|------|
| IPv6 | IPoE ネイティブ（LAN2 で DHCPv6-PD） |
| IPv4 | MAP-E トンネル（v6プラス経由） |
| PPPoE | **不要**（使用しない） |

> v6プラスではポート番号が自動的に割り当てられます（PSID方式）。
> ルーターが自動処理するためユーザー設定は不要ですが、
> **サーバー公開（ポート開放）はできません。**

---

## 必要なもの

| 項目 | 内容 |
|------|------|
| LAN ケーブル | ONU ↔ RTX830 LAN2、RTX830 LAN1 ↔ PC |
| PPPoE ID/PW | **不要**（v6プラスでは使わない） |

---

## 接続構成

```
[NTT ONU] ──(LANケーブル)──[RTX830 LAN2]  [RTX830 LAN1]──(LANケーブル)──[PC]
```

- **LAN2**: WAN側（ONU と接続、IPv6 IPoE を受ける）
- **LAN1**: 内部LAN（PC・スイッチと接続）

---

## 手順

### 1. 物理接続
1. RTX830 の **LAN2** ポートと NTT の ONU をケーブルで接続
2. RTX830 の **LAN1** ポートと PC をケーブルで接続
3. RTX830 の電源を入れる

### 2. 管理画面へアクセス
ブラウザで `http://192.168.1.1` を開く（初期パスワードは空欄）。

> Telnet / SSH でもアクセス可能: `telnet 192.168.1.1`

### 3. 設定コマンドの投入
`config.txt` の内容をそのままコピーして、管理画面のコマンド入力欄に貼り付けて実行する。

> PPPoE ID・パスワードの入力は **不要** です。

### 4. 接続確認

**IPv6 が取得できているか確認**
```
show ipv6 interface lan2
```
`グローバルIPv6アドレス` が表示されれば OK。

**MAP-E トンネルの状態確認**
```
show tunnel 1
```
`動作中` または `UP` と表示されれば OK。

**インターネット疎通確認**
```
ping 8.8.8.8
ping6 2001:4860:4860::8888
```
両方応答があれば IPv4/IPv6 ともに接続完了。

### 5. 設定保存
```
save
```
**必ず実行してください。** 実行しないと再起動で設定が消えます。

## 内部LAN 仕様

| 項目 | 値 |
|------|----|
| ルーター(ゲートウェイ) | `192.168.1.1` |
| DHCPの配布範囲 | `192.168.1.2` 〜 `192.168.1.191` |
| サブネットマスク | `255.255.255.0 (/24)` |
| IPv6 | RA で自動配布（PC 側は設定不要） |

---

## よくあるトラブル

| 症状 | 確認ポイント |
|------|-------------|
| `show ipv6 interface lan2` でアドレスが出ない | ONU〜LAN2 のケーブル確認。ONU のランプが正常か確認 |
| MAP-E トンネルが UP にならない | IPv6 が取得できてから数秒かかることがある。少し待って再確認 |
| IPv4 の ping が通らない | `show tunnel 1` でトンネル状態確認 |
| PCにIPが振られない | PC の NIC が「DHCPで取得」になっているか確認 |
| v6プラス確認サイトで判定されない | RTX830 の再起動後に数分待ってから再確認 |

---

## v6プラスの制限事項

- **ポート開放（サーバー公開）は不可** ── 割り当てポートが自動決定されるため
- **一部のオンラインゲーム** でポート問題が出ることがある（その場合はゲーム側のUPnP設定を試す）
- 割り当てポート範囲は `show nat descriptor address` で確認できる
