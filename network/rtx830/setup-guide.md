# YAMAHA RTX830 初期設定手順
NTT フレッツ光 + アンドライン (PPPoE)

## 必要なもの

| 項目 | 内容 |
|------|------|
| PPPoE接続ID | アンドラインの書類に記載（例: `xxxxxx@andline.ne.jp`）|
| PPPoEパスワード | 同上 |
| LAN ケーブル | ONU(光終端装置) ↔ RTX830 LAN2、RTX830 LAN1 ↔ PC |

---

## 接続構成

```
[NTT ONU] ──(LANケーブル)──[RTX830 LAN2]  [RTX830 LAN1]──(LANケーブル)──[PC]
```

- **LAN2**: WAN側（ONUと接続）
- **LAN1**: 内部LAN（PC・スイッチと接続）

---

## 手順

### 1. 物理接続
1. RTX830 の **LAN2** ポートと NTT の ONU をケーブルで接続
2. RTX830 の **LAN1** ポートと PC をケーブルで接続
3. RTX830 の電源を入れる

### 2. 管理画面へアクセス
1. PC のブラウザで `http://192.168.1.1` を開く
2. ユーザー名・パスワードは初期状態では空欄（そのままログイン）

> コマンドラインで設定する場合は Telnet `192.168.1.1` または SSH でも可

### 3. 設定コマンドの投入
1. `config.txt` を開き、以下の行を実際の値に書き換える

   ```
   pp auth myname [USER@andline.ne.jp] [PASS]
   ```

   例:
   ```
   pp auth myname abc123@andline.ne.jp MyPassword123
   ```

2. 書き換えたコマンドを全行コピーし、管理画面のコマンド入力欄に貼り付けて実行

### 4. 接続確認
```
show ppp
```
`状態: 接続` または `LCP opened` / `IPCP opened` と表示されれば OK。

```
ping 8.8.8.8
```
応答があればインターネット接続完了。

### 5. 設定保存
```
save
```
**必ず実行してください。** 実行しないと再起動で設定が消えます。

## IPv6 について

本設定は **PPPoE デュアルスタック**（IPv4 + IPv6 を同じ PPPoE で使う方式）です。

| 項目 | 内容 |
|------|------|
| IPv6アドレス配布 | DHCPv6-PD でプロバイダーから /64 プレフィックスを取得し、RA で PC へ配布 |
| フィルター | ICMPv6・確立済みTCP・DHCPv6 のみ許可。その他の外部→内部は拒否 |

### IPv6 接続確認
```
show ipv6 interface
show ipv6 route
ping6 2001:4860:4860::8888
```
IPv6 アドレスが表示され ping が通れば OK です。

> **IPoE（v6プラス / transix）を使いたい場合**
> アンドラインが IPoE サービスを提供しているか確認が必要です。
> 対応している場合は PPPoE とは別に tunnel インターフェースの設定が必要になります。

## 内部LAN 仕様

| 項目 | 値 |
|------|----|
| ルーター(ゲートウェイ) | `192.168.1.1` |
| DHCPの配布範囲 | `192.168.1.2` 〜 `192.168.1.191` |
| サブネットマスク | `255.255.255.0 (/24)` |

## よくあるトラブル

| 症状 | 確認ポイント |
|------|-------------|
| `show ppp` でエラーが出る | PPPoE IDとパスワードが正しいか再確認 |
| ping が通らない | ONU〜LAN2 のケーブルを確認。ONU のランプが正常か確認 |
| PCにIPが振られない | PCのNICが「DHCPで取得」になっているか確認 |
| 管理画面に繋がらない | PCのIPが `192.168.1.x` になっているか確認 |
