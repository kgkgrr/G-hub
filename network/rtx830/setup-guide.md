# YAMAHA RTX830 セットアップガイド
NTT フレッツ光 + アンドライン (IPoE / v6プラス MAP-E)

---

## 構成概要

```
[NTT ONU]
    │
    └─(LANケーブル)─[RTX830 LAN2]  [RTX830 LAN1]─(LANケーブル)─[WSR-3200AX4S LAN]
                                                                       │
                                                                    Wi-Fi
                                                              (スマホ・PC等)
```

| 項目 | 値 |
|------|----|
| ルーターIP / 管理画面 | `http://192.168.11.1` |
| サブネット | `192.168.11.0/24` |
| DHCP 動的配布 | `192.168.11.50` 〜 `192.168.11.191` |
| 固定割り当てゾーン | `192.168.11.2` 〜 `192.168.11.49` |
| IPv4 接続方式 | IPoE / v6プラス MAP-E（PPPoEは不要）|
| IPv6 接続方式 | IPoE ネイティブ（DHCPv6-PD）|

## RTX830 初期設定手順

### 1. 物理接続
1. RTX830 の **LAN2** ポートと NTT の ONU をケーブルで接続
2. RTX830 の **LAN1** ポートと PC（または WSR-3200AX4S）をケーブルで接続
3. RTX830 の電源を入れる

### 2. 管理画面へアクセス
ブラウザで `http://192.168.11.1` を開く（初期パスワードは空欄）。

> Telnet / SSH の場合: `telnet 192.168.11.1`

### 3. 設定コマンドの投入
`config.txt` の内容をそのままコピーして管理画面のコマンド入力欄に貼り付けて実行。

> PPPoE ID・パスワードの入力は **不要** です。

### 4. 接続確認

```
show ipv6 interface lan2   # IPv6アドレスが表示されればOK
show tunnel 1              # 「動作中」または「UP」であればOK
ping 8.8.8.8               # IPv4疎通確認
ping6 2001:4860:4860::8888 # IPv6疎通確認
```

### 5. DHCP固定割り当て確認

```
show dhcp scope    # スコープと固定バインドの一覧
show dhcp binding  # リース状況
```

### 6. 設定保存
```
save
```
**必ず実行してください。** 実行しないと再起動で設定が消えます。

## WSR-3200AX4S（Wi-Fiアクセスポイント）の接続

### 接続モードの選択

WSR-3200AX4S はデフォルトが「ルーターモード」です。
RTX830 配下に置く場合は **APモード（ブリッジモード）** に切り替えてください。
ルーターモードのまま使うと二重NAT（二重ルーター）になり、速度低下や通信不具合の原因になります。

### APモードへの切り替え手順

1. WSR-3200AX4S 背面の **AUTO/MANUAL スイッチ** を `MANUAL` にする
2. 背面の **ルーター切替スイッチ** を `AP` にする（機種により底面の場合あり）
3. 電源を入れ直す

> スイッチが見当たらない場合は管理画面 (`http://192.168.11.xxx`) →
> 「詳細設定」→「動作モード」→「アクセスポイント」で切り替え可能。

### ケーブルの接続先

| 接続元 | 接続先 |
|--------|--------|
| RTX830 LAN1 | WSR-3200AX4S **LAN ポート**（INTERNETポートは使わない）|

APモードでは WSR-3200AX4S の INTERNET(WAN) ポートは使用しません。

### WSR-3200AX4S の管理IP固定（推奨）

APモードでは WSR-3200AX4S 自身も RTX830 から IP を取得します。
管理画面に安定してアクセスできるよう、MACアドレスで固定IPを割り当てることを推奨します。

1. WSR-3200AX4S の MAC アドレスを確認（本体ラベルまたは管理画面）
2. `dhcp-static.txt` に追記して RTX830 に適用

```
dhcp scope bind 1 192.168.11.40 ethernet xx:xx:xx:xx:xx:xx  # WSR-3200AX4S
save
```

### 確認ポイント

| 確認項目 | 方法 |
|----------|------|
| APモードで動作しているか | WSR-3200AX4S 管理画面で動作モードを確認 |
| DHCPサーバーが無効か | APモードに切り替えると自動で無効になる |
| IPv6が透過されているか | PC で `ipconfig` を実行し、IPv6アドレスが取得できていればOK |
| インターネット接続 | PC から `ping 8.8.8.8` が通ればOK |

## トラブルシュート

| 症状 | 確認ポイント |
|------|-------------|
| IPv6 アドレスが取得できない | ONU〜RTX830 LAN2 のケーブル確認。ONU ランプが正常か確認 |
| MAP-E トンネルが UP にならない | IPv6 取得後、数秒〜数十秒かかる場合あり。`show tunnel 1` で再確認 |
| IPv4 の ping が通らない | `show tunnel 1` でトンネル状態確認 |
| PC に IP が振られない | PC の NIC が「DHCP で取得」になっているか確認 |
| 管理画面に繋がらない | PC の IP が `192.168.11.x` になっているか確認 |
| Wi-Fi は繋がるがインターネット不可 | WSR-3200AX4S が APモードか確認（ルーターモードのままだと二重NAT）|
| v6プラス確認サイトで判定されない | RTX830 再起動後に数分待ってから再確認 |

## v6プラスの制限事項

- **ポート開放（サーバー公開）は不可** ── 割り当てポートが自動決定されるため
- 割り当てポート範囲は `show nat descriptor address` で確認できる
- 一部のオンラインゲームでポート問題が出ることがある（UPnP を試す）
