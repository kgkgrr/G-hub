# RTX830 設定投入後 確認コマンド集
# 以下を上から順に実行して正常動作を確認すること
# -----------------------------------------------------------------------

# -----------------------------------------------------------------------
# 1. MAP-E トンネル状態
# -----------------------------------------------------------------------
show status tunnel 1
# 期待値: 「動作中」または「UP」、tunnel map-e type v6plus が表示される

# -----------------------------------------------------------------------
# 2. keepalive 状態（IPv4 / IPv6）
# -----------------------------------------------------------------------
show status keepalive 1
# 期待値: 監視先 8.8.8.8 に対して「正常（応答あり）」

show status keepalive 2
# 期待値: 監視先 2001:4860:4860::8888 に対して「正常（応答あり）」

# -----------------------------------------------------------------------
# 3. IPv6 プレフィックス確認
# -----------------------------------------------------------------------
show ipv6 prefix
# 期待値: dhcp-prefix@lan2 に有効な /64 プレフィックスが表示される

show ipv6 interface lan2
# 期待値: グローバル IPv6 アドレスが割り当てられている

# -----------------------------------------------------------------------
# 4. NAT テーブル確認
# -----------------------------------------------------------------------
show nat descriptor address
# 期待値: descriptor 1〜5 が表示され、outer が tunnel 側のアドレスになっている

show nat descriptor masquerade 1
# 期待値: 192.168.11.0/24 → tunnel のマスカレードエントリ

# -----------------------------------------------------------------------
# 5. ログ・SDカード保存確認
# -----------------------------------------------------------------------
show log
# 期待値: notice レベルのイベントが記録されている

show log save
# 期待値: SDカードへのログ保存状態・ファイル名が表示される
# ※ 表示されない場合は「dir sd:/」でSDカードのファイル一覧を確認

# -----------------------------------------------------------------------
# 6. 疎通確認（IPv4 / IPv6）
# -----------------------------------------------------------------------
ping 8.8.8.8
# 期待値: 応答あり（MAP-E トンネル経由 IPv4）

ping6 2001:4860:4860::8888
# 期待値: 応答あり（IPoE ネイティブ IPv6）
